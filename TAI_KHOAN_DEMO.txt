================================================================================
  Gợi ý chạy nhanh
================================================================================
  - API:  cd backend\QuangTrung.Api  rồi  dotnet run
  - Web:  cd frontend  rồi  npm run dev  → mở http://localhost:5173/login

  DevTools Console (F12): gõ
    await window.__QT_RUN_AUTH_API_TESTS__()
  để chạy self-test login/register qua đúng URL/proxy hiện tại; xem log [QT API] / PASS-FAIL.

================================================================================
  Nếu đăng nhập báo 500 / Internal Server Error
================================================================================
  - appsettings.Development.json: UseInMemoryDatabase = false → dùng PostgreSQL (mặc định).
  - Chuỗi kết nối và mật khẩu: xem appsettings.json (mặc định Password=123456 cho user postgres).
  - Tạo DB + migration chi tiết: đọc file TAO_DB_POSTGRES.txt hoặc chạy scripts\tao-db-postgresql.ps1 (cần psql trong PATH).
  - Nếu vẫn lỗi: F12 → Network → login → Response; xem console cửa sổ chạy dotnet run.
  - Vite có thể dùng cổng 5174 nếu 5173 bận — đã bật CORS cho cả hai.
  - Proxy FE phải trùng cổng API (mặc định http://127.0.0.1:5022 trong vite.config.ts).
